# Zapret for Keenetic / Netcraze

> [!WARNING]
> Проект предназначен для роутеров **Keenetic** и **Netcraze**.
> Работа на других устройствах не тестировалась и не гарантируется.

> [!NOTE]
> Скрипты выполняют только автоматическую установку.
> Настройка параметров `zapret` / `zapret2` после установки выполняется пользователем.

## Установка Zapret2 (рекомендуется)

```sh
curl -fsSL https://raw.githubusercontent.com/SNIPPIK/zapret-kn/main/install.sh | sh
```

## Установка Legacy Zapret

```sh
curl -fsSL https://raw.githubusercontent.com/SNIPPIK/zapret-kn/main/install_legacy.sh | sh
```
